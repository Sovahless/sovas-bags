# Sova's Bags

Module Foundry VTT pour **D&D 5e (règles 2024)** regroupant du contenu personnalisé (sous-classes, classes, objets, sorts, PNJ).

## Contenu

- **Paladin Oathbreaker (2024)** : Sous-classe complète avec aptitudes automatisées (*Conjure Undead*, *Dreadful Aspect*, *Aura of Hate*, *Supernatural Resistance*, *Dread Lord*) et sorts de domaine toujours préparés.
- **Sorcier Hexblade / Magelame (2024)** : Sous-classe complète (niveau 3) avec aptitudes automatisées (*Hexblade's Curse*, *Hex Warrior*, *Accursed Specter*, *Armor of Hexes*, *Master of Hexes*), sorts de patron toujours préparés et acteur Spectre Maudit prêt à invoquer.

## Installation

Dans Foundry VTT > **Modules complémentaires** > **Installer un module**, collez ce lien de manifeste :
```
https://raw.githubusercontent.com/Sovahless/sovas-bags/main/module.json
```
