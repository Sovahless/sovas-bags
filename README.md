# Sova's Bags

Module Foundry VTT (**v12–v14.370**) pour **D&D 5e (`6.1.0`, règles 2024)** regroupant sous-classes, espèces, aptitudes et compagnons personnalisés.

## Contenu

- **Paladin — Oathbreaker (2024)** : Aptitudes automatisées, invocations (*Skeleton*, *Zombie*) et sorts du *Player's Handbook*.
- **Sorcier — The Hexblade (2024)** : Aptitudes automatisées, compagnon *Accursed Specter* et sorts du *Player's Handbook*.
- **Espèce — Pixie (2024)** : Taille *Tiny*, vol 30 ft., *Fairy Magic* (*Druidcraft*, *Faerie Fire*, *Plant Growth*) et *City Fey*.
- **Espèce — Tabaxi (adapté 2024)** : Taille *Medium/Small*, escalade 30 ft., *Cat's Claws*, *Cat's Talent* et *Feline Agility*.

> **Recommandé** : activer le module `dnd-players-handbook` pour les sorts des sous-classes.

## Installation

Dans Foundry VTT > **Modules complémentaires** > **Installer un module**, collez ce lien de manifeste :
```
https://raw.githubusercontent.com/Sovahless/sovas-bags/main/module.json
```
